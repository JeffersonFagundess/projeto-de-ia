# Sons da interface

Efeitos selecionados do pacote **Kenney Interface Sounds 1.0**, publicado sob
Creative Commons Zero (CC0). Os WAVs são reproduzidos assincronamente pelo
Windows e não exigem biblioteca adicional.

Origem do pacote: <https://kenney.nl/assets/interface-sounds>

Conversão WAV utilizada: <https://github.com/Calinou/kenney-interface-sounds>

| Arquivo local | Arquivo do pacote | Evento |
| --- | --- | --- |
| `clique.wav` | `click_001.wav` | botão |
| `selecionar.wav` | `select_001.wav` | peça selecionada |
| `mover.wav` | `drop_001.wav` | movimento |
| `dica.wav` | `confirmation_001.wav` | previsão concluída |
| `erro.wav` | `error_001.wav` | ação inválida/erro |
| `fim.wav` | `bong_001.wav` | fim da partida |
| `alternar.wav` | `toggle_002.wav` | dicas abertas/fechadas |

A licença integral acompanha os arquivos em `LICENSE-KENNEY-CC0.txt`.
